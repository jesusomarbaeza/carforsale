# Car For Sale Records Workspace

## Folder Structure

- `documents/source-pdfs/service-records/`
	- Original service and shop PDFs (for example: Dodge, NAPA, Firestone, Tires, Title).
- `documents/source-pdfs/supporting-docs/`
	- Original supporting/manual PDFs from the old `Other` set.
- `documents/extracted/service-records/`
	- Extracted markdown summaries for service/shop PDFs.
- `documents/extracted/supporting-docs/`
	- Extracted markdown summaries for supporting/manual PDFs.

## Key Summary Files

- `car-history-summary.md`
	- Master summary with totals, chronology, and buyer-oriented narrative.
- `documents/extracted/supporting-docs/other-invoices.md`
	- Consolidated summary for non-priced supporting documents.

## Notes

- This layout replaces the older `inovices-pdfs/` and `invoices/` folders with clearer, type-based organization.
- Existing analysis content was preserved; only storage paths were reorganized.
